# 口述转书面任务

## 改写标准

先在内部概括“用户希望完成什么”，再写标题。零碎口述不是最终文案，即使只说了一件事，也需要检查句子是否通顺、动作与对象是否明确。

- 删除语气词、重复与“帮我记一下”这类助手指令；重组语序，补出原话明确蕴含的宾语和关联。
- 保留名称、金额、数量、方向、时间条件和否定。自我纠正采用最终版本；除非有追溯价值，不把已作废版本塞回备注。
- 标题独立可懂，不写“处理一下”“那个事情”，也不把每个词压成标签。没有机械字数上限；不能为了短而丢掉“修订后”“确认后”“不要发”等区别。
- 备注写有用背景、执行材料、验收要求或先后关系。无需每条都造一段备注，不保存没有用途的完整闲聊。
- 普通“要做”不等于高优先级；按用户明确的紧急程度设置。未说明时 `level=0`。
- 不把 API 时间解析器、正则去口头词或机械截断称作 AI 整理。语义工作由当前助手完成，无需新增模型服务或 API Key。

## 拆分标准

| 情况 | 处理 |
|---|---|
| 多件事互相独立 | 分别建任务，各自保留时间和对象 |
| 同一交付物的整理、检查、发送 | 通常一条任务，步骤放备注 |
| 用户明确安排了不同阶段/日期 | 分开并注明依赖；不要声称系统会自动解除依赖 |
| 完成目标很大但没有具体路径 | 记录明确的目标或下一步；不臆造整套项目计划 |
| “买牛奶和鸡蛋”，同一次购物 | 一条采购任务，保留两种物品与数量 |
| 一件事被反复描述 | 合并，不重复入库 |
| 已完成 A，接下来做 B | 匹配 A 后完成原任务，创建 B；无匹配时不造一个 A 再完成 |
| “先别联系客户，等合同确认” | 保留前提，不能创建无条件联系客户的提醒 |
| “可能看看要不要做” | 不升级为已承诺任务；按用户要求放想法备注或仅讨论 |

## 对照案例

以下人物、任务和情境均为虚构示例。

### 零碎单条也要重写

口述：“那个明天下午三点，你提醒我一下，就是王总那个报价，上次他不是说贵嘛，我把价格改改，然后发给他。”

- 标题：**修订报价单并发送给王总**
- 备注：王总反馈上次报价偏高，调整价格后再发送。
- 时间：核对“明天下午三点”的具体日期与时区；准时提醒。
- 一条任务足够，修改和发送共同形成这次报价交付。
- 通知正文同样是“修订报价单并发送给王总”，不会出现零碎口述。

### 自我纠正与独立任务

口述：“周三，不对周四上午十点跟小李对一下合同。牛奶也没了，下班顺路买两盒。”

- **与小李核对合同**：周四上午十点；原话没有要求推送时不要自动加推送。
- **下班后购买两盒牛奶**：保留两盒，不把“下班”编成 18:00。
- 作废的周三无需另建任务或保留为有效日期。

### 连续步骤不机械拆散

口述：“报销那个，发票先整理好，再看一下金额，最后提交一下。”

- 标题：**整理发票并提交报销**
- 备注：提交前核对报销金额。
- 不必拆成三次提醒；也不能改成“确认财务已经打款”。

### 明确阶段应拆分

口述：“今天先找设计师拿海报源文件，明天把尺寸改好发给运营，收到文件才能改。”

1. **向设计师索取海报源文件**：今天。
2. **调整海报尺寸并发送给运营**：明天；备注“收到设计师源文件后再调整”。

只记录用户已安排的两阶段，不新增审核、发布或跟进数据任务。

### 否定和条件不能丢

口述：“先别给客户发合同，等法务确认了再发。今天下午四点提醒我问问法务。”

- **向法务确认合同审核进展**：今天下午四点准时提醒。
- **法务确认后向客户发送合同**：保留条件，不设置无条件的今天发送提醒。
- 备注可以补充“法务确认前不要发送”。

### 背景不要变成待办

口述：“昨天跟小张吃饭，他说最近很忙。记一下明天把会议纪要发给他。”

只保存 **向小张发送会议纪要**，日期明天。不新增“与小张吃饭”“关心小张工作”等任务。

### 修改标题同步提醒语义

已有标题：“明天下午那个就是把报价弄好给王总”。用户：“把这条写通顺，提醒也改一下。”

先读原任务及备注确定意图，保存 **整理报价单并发送给王总**。沿用原提醒时刻与渠道，回读标题和最近提醒队列；不把提醒规则的“提前10分钟”改成任务标题。

### 尊重显式原文

口述：“标题就叫‘先活下来’，不要改字，记到收集箱。”

按用户要求保留 **先活下来**。默认整理不能覆盖用户明确指定的标题。

## 入库前检查

逐条对照原话：做什么、对象是谁、完成到什么程度、什么时候、有什么条件。时间表达是否已核对绝对日期？标题是否还像语音转写？所有独立行动是否都有去处，重复和否定是否误建？备注与提醒是否还在用纠正前的对象或日期？

这个检查由 AI 做语义判断。结构校验通过不等于文案通顺，也不能靠检测“嗯/那个”几个词代替。
