  一木清单 Cookie 获取方法（F12 开发者工具篇）
  更新日期: 2026-08-19 | 适用站点: yimutodo.com
============================================================

【重要前提】
vertx-web.session 是服务端 HttpOnly Cookie，
普通网页 JS(document.cookie) 默认读不到它的值。
下面三种方法按推荐程度排列。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法一（推荐，最简单）：Application 面板复制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 浏览器打开并登录 https://www.yimutodo.com
2. 按 F12 打开开发者工具
3. 点击顶部 "Application"(应用) 标签
4. 左侧展开 Cookies -> 点击 https://www.yimutodo.com
5. 在表格里找到 name = "vertx-web.session" 的那一行
6. 双击它的 "Value" 列，Ctrl+C 复制
7. 拼成下面的格式：
     vertx-web.session=复制的值
8. 将它填入项目根目录的 .env，切勿发给其他人或提交到 Git。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法二（一键）：油猴脚本 yimutodo_cookie_extract.user.js
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
随本包附带。安装 Tampermonkey 后导入该脚本，
刷新 yimutodo.com 页面，右上角搜索按钮左边会出现
一个剪贴板图标按钮，点击即自动复制：
    vertx-web.session=xxx
首次点击需在油猴弹窗里允许 "Cookie" 权限。

【补充说明】
- Cookie 会过期（失效时访问 API 返回 errorCode=1000004 登录失效）
- 更新方法: 重新登录网页版 -> 方法一重新复制
- Cookie 等同于当前登录态。不要粘贴到聊天、Issue、日志或公开仓库。
